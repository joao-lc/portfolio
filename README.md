# Portfólio Interativo — João Augusto Oliveira Lacerda

Página pessoal e currículo dinâmico desenvolvido em **HTML5, CSS3 e JavaScript puro (Vanilla JS)**, projetado para facilitar a triagem técnica de recrutadores.

## Funcionalidades
- **Lente do Recrutador:** Filtro dinâmico que destaca experiências, projetos e certificações conforme o perfil da vaga (Desenvolvimento & IA, QA, Infraestrutura/Redes ou Docência/Gestão).
- **Terminal Interativo (CLI):** Simulador de linha de comando para consulta rápida de stack, contatos e atuação.
- **Modais de Arquitetura:** Detalhamento técnico dos projetos em Python (IA), Three.js (WebGL), WordPress/WooCommerce e Excel VBA.
- **Modo Impressão / PDF:** Folha de estilo dedicada (`@media print`) que converte a página em um currículo limpo para exportação em PDF.

## Stack Utilizada
- HTML5 Semântico
- CSS3 (Variables, Grid, Flexbox, Media Print)
- JavaScript ES6+ (DOM Manipulation, Event Listeners)
